Blind Relay

Who can read a request? The relay sees the client’s network address. The gateway reads the inner request. Writing your name or account ID inside that request can identify you to the gateway. A fresh encapsulation key changes the encrypted envelope. Repeated details in the request can still link visits. Oblivious HTTP privacy considerations (RFC 9458).

DNSSEC Chain

Which clock produced the verdict? At the capture instant the pinned chain validates. Move the clock to +400 days and the recorded signature has expired. If you switch while verification is running, a result from the earlier clock can arrive last. Select the intended clock again after the previous result settles.

Enigma Forge

What does matching a crib establish? A crib is a passage of expected plaintext. In this lesson, a setting that reproduces that passage can still give wrong letters elsewhere in the message. You can check the machine itself with rotors I–II–III, rings and starting positions AAA, reflector B and an empty plugboard. Enter AAAAA for BDZGO, then enter BDZGO with the same starting settings to recover AAAAA.

Factor Forge

What does the tree establish? Enter 97, then clear the field. A tree that still shows 97 belongs to the previous input. For a large integer tested with random bases, a passing result means “probably prime.” The deterministic range shown in the exercise supports a definitive verdict.

GGH Trapdoor

How do you check a decoded point? The two bases describe the same lattice. Compare each decoded lattice point with the starting lattice point from that run. Both bases can give the right answer for a small error. Changing the sampled error can change which answers match.

Masked Core

Where does the AES round key go? Suppose the two shares are a and b, and the round key is k. XOR the round key into one share. Recombining gives (a ⊕ k) ⊕ b = (a ⊕ b) ⊕ k. Applying the same key to both shares cancels it, because k ⊕ k = 0.

Matsui Line

What does a balanced pair mean? Select a mask pair whose two parities agree on 8 of the 16 inputs. Its correlation is zero. This result belongs to that input mask and output mask. No four-bit permutation balances every nontrivial mask pair.

Misty Lens

Which results belong to the current block? Open the corrected MISTY1 and KASUMI block exercise. Remove a hex digit from the block or key and seven old outputs clear. Restore the digit to recompute. The labels follow the Encrypt or Decrypt setting.

PQ Families

Which bytes does the handshake chart count? The chart adds the selected key shares, certificate public keys and signatures. Its P-256 comparison counts 64 raw bytes per public key and 64 per signature before encoding. A TLS capture also contains certificate fields, framing and extensions. The exhibit’s hybrid switch adds classical authentication as well as classical key agreement. The standardized hybrid groups specify key agreement. TLS 1.3 (RFC 8446) and hybrid TLS groups (RFC 10024).

Rekey Relay

What did the proxy journal find? The journal searches for the exact UTF-8 bytes of the current message. The single character é uses two bytes. With an empty message or journal, the comparison is pending. A short byte sequence can match by coincidence. An unsuccessful search only establishes that the literal bytes did not occur in the recorded fields.

Reshare Circle

Where does generator 4 come from? The lab uses the 2048-bit prime p from RFC 3526 §3. That specification gives generator 2. The lesson squares it to obtain 4 and uses that generator in the subgroup of order (p − 1)/2.

Search Vault

Which query does a verdict describe? The returned rows belong to the keyword you submitted. After editing the keyword, run the search again. After changing the server behavior, rerun the integrity check. A green result left on screen from the previous settings describes that earlier response.

Shelf Oracle

How much of the catalog has been processed? After one step the server has processed one of the 64 records. Stepping eight more brings the total to nine. Before the selected record, the running sum can decrypt to zero even when the ciphertext coefficients are nonzero. At step 64, with enough noise budget, the final sum decrypts to the selected record.

Simon Period

What is the textbook promise? For a nonzero secret s, the promise is f(x) = f(y) exactly when y = x or y = x ⊕ s. The first case matters because every input has the same output as itself. The performance comparison describes how query counts grow with input width. Either method can finish first in one small trial.

SM2 Forge

Which inputs distinguish the two layouts? C2 holds the encrypted message. When the message is empty, C2 has zero bytes, so the orders C1C2C3 and C1C3C2 produce identical bytes. For the text round trip, an initial U+FEFF entered as message content counts as a character. Check that it comes back even though it is invisible.

Syndrome Hints

Which standards milestone belongs to each scheme? ISO/IEC standardized Classic McEliece in June 2026. NIST selected HQC for standardization in March 2025. The small decoding examples in the lesson illustrate a mathematical problem. Their timings describe only the instances shown. ISO/IEC 18033-2, Amendment 2 and NIST’s HQC selection.

Traitor Trace

How many wraps at the two endpoints? With zero subscribers revoked, one wrapped copy of the session key covers the whole tree. With everyone revoked, zero wraps are needed. The subset-difference bound of 2r − 1 applies when the number revoked, r, is at least one and smaller than the total number of subscribers.

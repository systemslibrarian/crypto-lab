Follow your curiosity

Each game offers a path into deeper learning. Sealed Showdown uses real SHA-256 commitments in a local practice match; Quantum Courier is a classical simulation of simplified BB84 measurement rules; Merkle Mystery computes real hashes and inclusion proofs for fictional collectibles; Key Rush uses small-parameter Shamir sharing; Lattice Builder teaches integer vector steps and basis changes through a small navigation puzzle. Mental Poker and Coin Flip Challenge compute SHA-256 commitments for locally simulated opponents; The Digital Trade computes real item hashes in a simulated escrow. None implements a production-secure remote protocol. These games are educational, not tools for protecting real secrets.

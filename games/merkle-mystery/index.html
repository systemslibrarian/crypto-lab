Each jump calculates SHA-256 over byte 01, the full left hash, then the full right hash. The item’s first hash uses byte 00 followed by UTF-8 JSON [title, description]. Short labels are for display; verification uses all 32 bytes.

Range labels and sibling checks are puzzle guidance. They are not authentication. The final verifier independently recomputes the proof from the delivered item, its position, the tree size, and the supplied hashes.

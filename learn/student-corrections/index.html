AEGIS Gate

Which bytes belong to the message? In the encrypt/decrypt exhibit, a leading U+FEFF is part of the text you enter. The UTF-8 bytes for U+FEFF followed by the letter A are ef bb bf 41. The letter A by itself is 41. The original display can make both messages look like A after a successful decryption. Check the ciphertext length: four bytes for the first message, one for the second, with either tag length.

To inspect a decrypted UTF-8 message in JavaScript while preserving that first character, use new TextDecoder('utf-8', { ignoreBOM: true }).decode(bytes). Encoding Standard, TextDecoder

Babel Hash

What gets hashed when a bit flip breaks a character? Enter A on the Avalanche tab, select SHA-256 and flip input bit 0. The exhibit counts from the high bit. The input byte 41 becomes c1, which cannot occur in valid UTF-8. SHA-256 still takes that byte as input. Its digest begins d1bbd73b, and 131 of the 256 output bits change.

Now flip bit 7 of the original A. The result is 40, the UTF-8 encoding of @. Its digest begins c3641f85, and 136 bits change. Replacing an invalid byte with the displayed character � would hash three different bytes, ef bf bd.

Blind Relay

Who can read a request? The relay sees the client’s network address. The gateway reads the inner request. Writing your name or account ID inside that request can identify you to the gateway. A fresh encapsulation key changes the encrypted envelope. Repeated details in the request can still link visits. Oblivious HTTP privacy considerations (RFC 9458).

Ciphertext Mirror

Does every bad ciphertext produce a fallback secret? Suppose an ML-KEM-768 receiver has a valid decapsulation key. Predict the result for a ciphertext of 1,087 bytes, then for a 1,088-byte ciphertext that fails the re-encryption comparison.

The 1,087-byte input gives a length error. The 1,088-byte input reaches the comparison. A mismatch returns a 32-byte fallback secret. A match also returns a 32-byte secret. The caller receives no match flag. The required ciphertext lengths are 768, 1,088 and 1,568 bytes for ML-KEM-512, ML-KEM-768 and ML-KEM-1024, respectively.

Open Ciphertext Mirror · FIPS 203 §7.3 and Algorithm 18

Collision Vault

What do the two SHAttered PDFs show? The files have different contents and the same SHA-1 digest. Compare their SHA-256 digests in the original exhibit to tell them apart. The authors report roughly 6,500 CPU-years and 100 GPU-years of computation. Read the paper at CWI for their measurements.

The announcement came in February 2017. Chrome had already announced its SHA-1 certificate retirement schedule in November 2016.

Corrupted Oracle

What happens at p = 0.01? At the 1% significance level used here, NIST’s rule rejects the sample when the measured p-value is below 0.01. An exact value of 0.01 passes this test. For example, 0.00999 fails, 0.01000 passes, and 0.01001 passes. A rounded display of 0.010 can hide which value was measured.

A pass describes one statistical test on one sample. Even predictable output can pass. NIST SP 800-22 Rev. 1a, §2.2.5–2.2.6

DNSSEC Chain

Which clock produced the verdict? At the capture instant the pinned chain validates. Move the clock to +400 days and the recorded signature has expired. If you switch while verification is running, a result from the earlier clock can arrive last. Select the intended clock again after the previous result settles.

Enigma Forge

What does matching a crib establish? A crib is a passage of expected plaintext. In this lesson, a setting that reproduces that passage can still give wrong letters elsewhere in the message. You can check the machine itself with rotors I–II–III, rings and starting positions AAA, reflector B and an empty plugboard. Enter AAAAA for BDZGO, then enter BDZGO with the same starting settings to recover AAAAA.

Factor Forge

What does the tree establish? Enter 97, then clear the field. A tree that still shows 97 belongs to the previous input. For a large integer tested with random bases, a passing result means “probably prime.” The deterministic range shown in the exercise supports a definitive verdict.

Falcon Seal

Which lattice point is closest? Enter the same integer target here and in the original playground. Both bases describe the same lattice. Rounding the two basis coordinates independently can give a different answer in each basis. Compare the squared distances to find out whether either answer is closest.

Target coordinates

At (6, 16), the minimum squared distance is 292 at (0, 0). The short basis rounds to (−4, 30), squared distance 296. The skewed basis rounds to (28, 34), squared distance 808.

Try (16, 2) for a tie. Any point at the minimum distance is a correct answer. Falcon signing uses its secret basis to sample a sufficiently short vector satisfying the verification equation. Falcon specification, signing and verification

GGH Trapdoor

How do you check a decoded point? The two bases describe the same lattice. Compare each decoded lattice point with the starting lattice point from that run. Both bases can give the right answer for a small error. Changing the sampled error can change which answers match.

Harvest Timeline

When does a three-year planning shortfall leave zero sensitive years for a particular record? Start in 2026. A record must stay secret for five years, migration takes ten years, and the scenario places quantum arrival twelve years away in 2038. The planning shortfall is 5 + 10 − 12 = 3 years. The record’s secrecy requirement ends in 2031, seven years before the assumed arrival. The timing calculation alone cannot establish that the record would still be sensitive then.

Compare the completion year with the arrival year in the delay table. If they are equal, migration finishes at arrival and has zero years to spare. The original table can label that case “BEAT CRQC.” In the CSV, read the column labelled “Exposed (X+Y > Z)” as the timing comparison and consider the asset’s actual confidentiality mechanism separately.

Harvest Vault

Can a record expire before Q-Day while its library is already late to migrate? In the worked calculator example, a library starts planning in 2026. A notice stays sensitive for five years (X), migration takes six years (Y) and the assumed quantum arrival is eight years away (Z), in 2034.

A notice issued today expires in 2031. A notice issued just before migration finishes in 2032 can stay sensitive until 2037. That gives a three-year planning shortfall even though today’s notice has zero sensitive years left in 2034. Starting migration in 2028 would finish it in 2034. To allow both migration and the last notice’s five-year shelf life by 2034, the latest start would have been 2023.

The dates are assumptions. The calculator cannot tell whether anyone recorded a session. A later upgrade cannot change the protection on a copy someone already holds. NIST IR 8547 §3 · RFC 8784 §1

Iron Letter

Does Bob see the exact text Alice sealed? Generate the keys, copy the whole sample into Alice’s message, seal it for Bob and open it with his key. Try ECIES P-256, RSA-2048 or RSA-4096. Each should return the same 25 UTF-8 bytes, including the line break and the two spaces at the end.

If the opened text contains 22 bytes, the text decoder consumed the first three bytes, EF BB BF. The encrypted message still contained them. Spaces and line breaks can also look different when the result display collapses whitespace.

Open Iron Letter · WHATWG Encoding Standard, TextDecoder

Jevil

How many polynomials fit three points? Choose budget 1, two positions per signature and the Goldilocks base field. Generate a key and sign one message with the honest signer. The meter reads 3 / 4. There are exactly 18,446,744,069,414,584,321 polynomials of degree at most three that fit those three points.

A cubic has four coefficient slots. Once you choose the coefficient of the cubic term, the three points determine the other three coefficients. The field offers one choice for each of its q elements, including zero. That zero choice gives a polynomial of degree at most two.

The exact count here is q = 264 − 232 + 1. A verdict of “Exactly 2^63” rounds down to a power of two. With the tower field selected, the same 3 / 4 meter leaves q4 choices. Signing the same message again with the same key leaves the meter and the count unchanged.

Kerberos

What does a Kerberos client need to use a service ticket? The client sends the ticket with a fresh authenticator encrypted with the associated session key. The encrypted ticket alone cannot create that authenticator. Protect the credential cache because it holds both pieces. See RFC 4120 §3.2.2.

In the original lesson, try the clock at +5 minutes, then +6 minutes. The first is accepted and the second is rejected. Five minutes is the configurable MIT Kerberos default.

What proves the service’s identity to the client? Compare ctime and cusec in the last two messages. The service echoes both fields in an encrypted AP-REP. To authenticate the service, the client must decrypt and verify that reply with its ticket session key and compare both values with its own request. Seeing a sixth message is evidence that the service replied. The client’s checks establish mutual authentication. RFC 4120 §3.2.5

LMS + HSS Vault

Which leaf can sign next? In the original lesson, generate a fresh LMS tree and sign the same notice twice. The first signature uses leaf 0 and the second uses leaf 1. The message can stay the same. Each signature spends a different one-time key.

A height-10 tree starts with 1,024 leaves. After two reservations, its next index is 2 and 1,022 leaves remain. Suppose a signer reserves leaf 2 and loses power before it can confirm delivery. Recovering safely means keeping leaf 2 spent. The next signature can use leaf 3. A signer that keeps its private key across restarts must save the advanced index before releasing a signature. RFC 8554 §5.4.1

Masked Core

Where does the AES round key go? Suppose the two shares are a and b, and the round key is k. XOR the round key into one share. Recombining gives (a ⊕ k) ⊕ b = (a ⊕ b) ⊕ k. Applying the same key to both shares cancels it, because k ⊕ k = 0.

Matsui Line

What does a balanced pair mean? Select a mask pair whose two parities agree on 8 of the 16 inputs. Its correlation is zero. This result belongs to that input mask and output mask. No four-bit permutation balances every nontrivial mask pair.

McEliece Gate

How much of a key does the preview show? The key-size panel shows 8,192 simulated bytes, or 8 KiB. Each pair of hex digits represents one byte. A complete mceliece348864 public key occupies 261,120 bytes, or 255 KiB. In decimal units that is 261.12 kB. The preview illustrates the size. Its random-looking bytes do not establish that a working key was generated. Parameter sizes and binary unit definitions.

NIST selected HQC in its fourth-round decision in 2025. ISO/IEC published the Classic McEliece amendment in June 2026.

NTRU Classic

What did the decryption check compare? The success message means that the recovered polynomial matches the message polynomial. The original text display drops a leading U+FEFF when it decodes those bytes. That character is invisible but occupies three UTF-8 bytes. In this example the message has 17 bytes and the recovered text shown on the original page has 14.

ORAM Vault

Will my text fit in one block? The custom editor stores up to 32 UTF-8 bytes. Eight 📚 characters take exactly 32 bytes. Nine take 36. A leading U+FEFF followed by A takes four bytes (ef bb bf 41), even if the readout looks identical to the one-byte message A.

The text editor pads short blocks with zero bytes. A U+0000 at the end of a message therefore looks exactly like padding on readback. The original field can also truncate a long paste before it checks the byte count. Read back the value you intended to store and compare its UTF-8 bytes. Encoding Standard, UTF-8

OT Gate

Did the receiver get everything the sender typed? In the original lesson, the sender’s form trims both messages before encrypting them. Try the sample below as message zero, then choose zero. Its first character is U+FEFF, followed by two spaces. It also ends with two spaces. The receiver shows “Café 🔐” (10 UTF-8 bytes) although the sender entered 17. The form changed the text before the transfer.

Pairing Gate

What would a future break of BLS mean for an old signature? Imagine two copies of a signed record. One has only the BLS signature. The other also has an independent trusted timestamp obtained while the signature was trustworthy. Once someone can recover the BLS key, a newly made signature can pass the same verification as an old one. The timestamp can still establish that the second signed record existed by a particular time, provided the archive renewed its evidence before its protections weakened. It does not establish who physically used the key.

RFC 3161, timestamping a signature · RFC 4998, renewing archival evidence

PQ Families

Which bytes does the handshake chart count? The chart adds the selected key shares, certificate public keys and signatures. Its P-256 comparison counts 64 raw bytes per public key and 64 per signature before encoding. A TLS capture also contains certificate fields, framing and extensions. The exhibit’s hybrid switch adds classical authentication as well as classical key agreement. The standardized hybrid groups specify key agreement. TLS 1.3 (RFC 8446) and hybrid TLS groups (RFC 10024).

PSI Gate

How should I read the published hex strings? The scalar for Alice is the integer seven. PSI Gate displays it in 32 bytes ending in 07. The points use the canonical little-endian ristretto255 encoding. Copy each point in the byte order shown. The OPRF tags are SHA-256 digests, also copied in output order.

The example calls for a scalar of seven even if your library accepts a scalar as 32 little-endian bytes beginning with 07. Applying seven to the first hashed input gives a point beginning 90 e6 2d 0f. The final intersection contains Bob’s and Mom’s addresses. RFC 9496, ristretto255 encoding · Published vector bytes

Rekey Relay

What did the proxy journal find? The journal searches for the exact UTF-8 bytes of the current message. The single character é uses two bytes. With an empty message or journal, the comparison is pending. A short byte sequence can match by coincidence. An unsuccessful search only establishes that the literal bytes did not occur in the recorded fields.

Reshare Circle

Where does generator 4 come from? The lab uses the 2048-bit prime p from RFC 3526 §3. That specification gives generator 2. The lesson squares it to obtain 4 and uses that generator in the subgroup of order (p − 1)/2.

Search Vault

Which query does a verdict describe? The returned rows belong to the keyword you submitted. After editing the keyword, run the search again. After changing the server behavior, rerun the integrity check. A green result left on screen from the previous settings describes that earlier response.

Shelf Oracle

How much of the catalog has been processed? After one step the server has processed one of the 64 records. Stepping eight more brings the total to nine. Before the selected record, the running sum can decrypt to zero even when the ciphertext coefficients are nonzero. At step 64, with enough noise budget, the final sum decrypts to the selected record.

Simon Period

What is the textbook promise? For a nonzero secret s, the promise is f(x) = f(y) exactly when y = x or y = x ⊕ s. The first case matters because every input has the same output as itself. The performance comparison describes how query counts grow with input width. Either method can finish first in one small trial.

SM2 Forge

Which inputs distinguish the two layouts? C2 holds the encrypted message. When the message is empty, C2 has zero bytes, so the orders C1C2C3 and C1C3C2 produce identical bytes. For the text round trip, an initial U+FEFF entered as message content counts as a character. Check that it comes back even though it is invisible.

SPHINCS Ledger

Select SHA2-128f and sign a classroom message. Predict the public key size before opening the mechanism view. The top tree root occupies 16 bytes. The public seed occupies another 16 bytes, giving a 32-byte public key in the order PK.seed || PK.root.

The 17,088-byte signature includes a 16-byte randomizer, a 3,696-byte FORS signature, and 13,376 bytes of hypertree signatures. A bottom leaf address can be selected again. The WOTS+ key at that address still signs the same FORS public key.

Syndrome Hints

Which standards milestone belongs to each scheme? ISO/IEC standardized Classic McEliece in June 2026. NIST selected HQC for standardization in March 2025. The small decoding examples in the lesson illustrate a mathematical problem. Their timings describe only the instances shown. ISO/IEC 18033-2, Amendment 2 and NIST’s HQC selection.

Traitor Trace

How many wraps at the two endpoints? With zero subscribers revoked, one wrapped copy of the session key covers the whole tree. With everyone revoked, zero wraps are needed. The subset-difference bound of 2r − 1 applies when the number revoked, r, is at least one and smaller than the total number of subscribers.

Can two revocations give different header sizes? Try two pairs in the 16-subscriber tree. Revoking #1 and #2 needs three complete-subtree wraps or one subset-difference wrap. Revoking #1 and #9 needs six or two, respectively. A separate wrap for each allowed subscriber would need 14 in either case. The count depends on where the revoked leaves sit in the tree. See the original subset-cover construction, sections 3.1–3.2.

What do 960 bytes count? Sixteen separate AES-GCM key wraps contain 960 bytes: each has a 12-byte IV, a 32-byte encrypted session key, and a 16-byte tag. The exhibit stores the subset identifier separately and omits it from the byte counter. A complete wire header would also need to encode the recipients or subsets and any framing required by its format.

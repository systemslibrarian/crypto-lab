**185** exhibits have a test file whose name contains `claims`; **58** have no matching filename. **55** have paths named for mutations. These are discovery signals, not coverage or quality scores. A claims file can be uninvoked, incomplete, or wrong; a lab without that filename can test its displayed claims elsewhere. A mutation script or report does not prove a successful mutation run.

**Execution and mutation-tested status: NOT ASSESSED by this census for every row.** Do not turn file presence into a “verified” badge. The remediation review records separately which changed labs were actually tested.

Misty Lens

Encrypt one block with MISTY1 and KASUMI. Then delete a key digit and switch to Decrypt. Which results disappear? Restore the digit and check that both ciphers recover the input block.

Crypto Lab · Paul Clark. This standalone edition contains the block-cipher exercise from the classroom correction. It runs offline.

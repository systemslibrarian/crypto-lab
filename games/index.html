Follow your curiosity

Each game offers a path into deeper learning. Sealed Showdown uses real SHA-256 commitments in a local practice match; Quantum Courier is a classical simulation of simplified BB84 measurement rules; Merkle Mystery computes real hashes and proofs in a fictional archive; Secret Council uses small-parameter Shamir sharing; Lattice Builder’s opening puzzle is a geometric analogy. These games are educational, not tools for protecting real secrets.

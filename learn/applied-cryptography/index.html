What the coverage labels mean

Direct coverage A linked experiment addresses a selected chapter concept. It does not promise complete chapter coverage.

Modern counterpart A later construction explores a related goal; the implementation differs from the book.

Introductory coverage Builds intuition or offers a partial bridge. Read the boundary before treating it as a protocol implementation.

Keep the book, the demo and the claim distinct

Start with the author’s official table of contents. Follow each exhibit’s sources and implementation limits. Historical coverage is not current deployment advice, and a passing experiment is not a security proof.
